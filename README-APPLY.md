# 카톡방탈출 v34: 실제 구조 개편 / 통합 검증

## 적용 방법

압축 내 경로 그대로 기존 GitHub 저장소에 덮어쓰고 커밋하세요. `src/game` 및 `src/app/Game.tsx`는 함께 적용해야 합니다. 이전 v33 테스트 수정도 이번 패키지에 통합했습니다.

## 새 구조

- 1~4장의 실제 선택 이력에서 8차원 캐릭터·플레이 성향 기억을 계산합니다. 기존 저장 데이터와 충돌하지 않도록 `story.history`를 단일 원천으로 이용합니다.
- 3장/4장/5장에서 누적 기억에 맞는 **조건부 실제 채팅 메시지**를 표시합니다. 얻지 못한 메시지는 런타임에서 생략합니다.
- 5장에서 7개 엔딩 선택지를 제거하고 `그냥 조용히 채팅을 끝낸다`, `이 상황 자체를 따져본다`, `내가 직접 정리해 본다`의 3개 행동을 표시합니다. 누적 이력과 행동으로 E01~E07을 결정합니다.
- 메뉴의 채팅방 나가기는 스토리 선택지 여부와 관계없이 재생 중/선택 중 1~5장 모두 동작하도록 `leaveChat` 엔진 API를 구현했습니다. 각 장에서 자연스러운 재초대/결말로 이어집니다.
- 1장 첫 선택까지 메시지 속도를 조정하고 비탈퇴 2장 진입을 유지했습니다.
- E04는 퇴장 이후 채팅이 없으며, E06/E07은 퇴장 후 관전 메시지만 출력하는 기존 계약 유지.

## 검증 결과

**이 컨테이너에서 실제 실행**
- `tsc` 강한 타입 검사: `story.ts`와 `runtime.ts` 통과
- Node 오프라인 엔진 테스트 8종 통과 (`redesign`, `routes`, `preflight`, `spectator`, `runtime`, `escape-contract`, `balanced-flow`, `all-endings`)
- 그래프 탐색: 10,513개 상태, 11,966개 전이, E01~E07 모두 도달
- 1~5장 재생 도중 공통 나가기 명령 테스트 통과
- E04, E06, E07 퇴장/관전/세이브 계약 검증 통과

**아직 이 컨테이너에서 실행하지 못한 항목**
- Next.js 전체 빌드 / React TSX 전체 프로젝트 타입 검사
- Playwright 실제 브라우저 E2E: 이 실행 환경에 해당 프로젝트의 npm 의존성과 Chromium이 없고 외부 설치 네트워크가 차단됨. 대신 7개 엔딩과 메뉴 나가기 E2E 테스트 코드를 업데이트/추가했습니다.

GitHub 반영 후 CI의 `npm run check`, `npm run build`, `npm run test:e2e` 결과가 모두 녹색인지 확인해야 최종 배포 통합 테스트까지 완료입니다.
