# 카톡방탈출 — Next.js 단톡방 탈출 게임

Next.js 모바일 가상 메신저 플레이어블 프로토타입. v10에서 대사 68곳을 감수한 스토리(42개 노드, 7개 엔딩)와 런타임을 포함.

## v10 변경 사항

- 실제 친구 단톡방에 가까운 짧은 반문·맞장구·말투로 대사 68곳 수정.
- E05, E06, E07의 반전 메시지 전 정적 보강.
- 노드 ID와 선택지 조건 변경 없이 7개 엔딩 도달 경로 재검증.
- `npm run test:offline` 통과: 1,504개 상태, 엔딩 7/7.
- 브라우저 빌드 및 모바일 E2E는 아직 미검증.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 열어 플레이. `npm run check`로 타입 검사.

## 구현 범위

- 개별 말풍선 순차 자동 도착, 발신자별 입력 중 표시
- 답장 후보 선택 후 전송, 읽씹·행동형 선택
- 게임 내 나가기 확인 및 가상 채팅방 재초대
- 모바일 채팅방 목록·말풍선·엔딩 UI
- 속도 1x/1.5x, 일시정지, 선택 경계까지 스킵
- 로컬 저장 및 복원, 새 게임
- 기존 7개 엔딩/42개 노드 연동

## 미완성 / 알려진 제한

- 상태 엔진 자체는 v7 PoC 기반이며, 일부 엔딩 연출의 방 소속과 참여자 수는 아직 실제 메신저 수준으로 완벽히 반영하지 않음.
- 초대 알림/퇴장 목록 전환은 단순화되었고, 메신저 푸시 알림은 없음.
- 입력 중 스케줄은 이벤트 단위로 작동하되, 속도 변경 시 해당 이벤트의 대기 시간이 처음부터 다시 시작될 수 있음.
- 자동 브라우저 E2E는 별도 실행 필요. 수동 재생/스크롤/화면 테스트 권장.
- 실제 카카오톡과 무관한 패러디 게임. 네트워크 전송 없음.
