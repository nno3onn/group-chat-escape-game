# 카톡방탈출 v53 — 스토리 완성도 개선

**핵심 반전**: 초대한 한 사람만 문제였던 게 아니라, 각자 다른 이유로 방을 보존해 온 친구들 모두가 단톡방을 나갈 수 없는 상황을 만든다는 사실이 4장에서 드러납니다.

### 변경 사항
- 1장: 채팅방 최초 생성과 오래된 캡처에 대한 복선 추가
- 2장: 단순 재초대 범인 찾기와 채팅방이 늘어나는 이유 구분
- 3장: 말이 없는 것과 채팅방이 없어지는 것은 다르다는 단서
- 4장: 친구 4명의 동기를 모아서 단톡방 '공동명의' 반전 전개
- 4장 선택지 이후 캐릭터별 반응 강화
- E01/E02/E03/E05/E06/E07 엔딩에 기존 대사 회수와 추가 반전
- **E04는 무대사 엔딩 정체성을 보존해 미수정**

선택지 ID, 엔딩 판정, 스탯, 룸 처리, 플레이 API 변경 없음. 대사 추가로 플레이 시간은 다소 늘어납니다.

### 적용
1. `apply_v53.py`를 프로젝트 최상위 폴더에 복사
2. 터미널에서 실행:

```bash
python3 apply_v53.py
npm run check
npm run test:offline
npm run test:e2e
```

3. iOS에 반영하려면 `npm run build:mobile && npx cap sync ios`, Xcode에서 `Cmd+R`.

이 스크립트는 기준 문구가 다르면 **아무것도 수정하지 않고 중단**합니다. 이미 적용한 문구는 재적용하지 않습니다.
