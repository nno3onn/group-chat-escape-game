# v56: 이미 보낸 답장 선택지 숨기기

- 한 플레이에서 이미 **전송한 답장**과 동일한 문구는 다음 답장 목록에서 제외합니다.
- `history`의 선택지 ID와 채팅방에 실제 남아 있는 내가 보낸 답장의 문구를 비교합니다.
- ‘채팅방 나가기’/‘조용히 나가기’ 등의 **행동 버튼은 유지**합니다.
- 선택지 전체가 사라지는 경우 원래 목록을 보이도록 해 진행 불가능한 상태를 방지합니다.
- 기존 저장 상태를 별도 마이그레이션하지 않습니다.

## 적용
프로젝트 최상위 디렉터리에 `apply_v56.py`를 복사하여 아래 실행:

```sh
python3 apply_v56.py
npm run check
npm run test:offline
npm run test:e2e
```

추천 커밋: `feat: 이미 전송한 답장 선택지 재등장 방지`

> 게임 자체를 플레이하는 브라우저 E2E 테스트는 사용자 환경에서 실행해 주세요.
