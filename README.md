# 카톡방탈출 v54 — 탈출 성공 조건 강화

이번 패치는 기존 GitHub 코드에 **엔딩 판정 1개 함수만 변경**하고 E04/E06 테스트 경로를 갱신합니다. 다른 5개 엔딩 판정 및 화면 구성은 유지합니다.

- E04: 1장 약속 미루기 → 조용히 나가기 → 2장 알림 문제 설명 → 3장 침묵 선택 → 4장 퇴장 재확인
- E06: 1장 일정 논의에 참여 → 투표 다시 올리기 → 나가기 → 2장 퇴장 허락 요청 → 3장 투표로 확인 → 4장 재확인
- 1장에서 곧바로 퇴장하고 마지막에 허락만 구하던 기존 성공 루트는 E03 실패로 변경됩니다.
- 새 회귀 테스트에서 두 정상 성공 루트와 쉬운 루트 실패를 검증합니다.

## 적용
ZIP에서 `apply_v54.py`를 프로젝트 루트에 복사한 뒤:

```bash
python3 apply_v54.py
npm run check
npm run test:offline
npm run test:e2e
```

시뮬레이터 업데이트:
```bash
npm run build:mobile
npx cap sync ios
```
Xcode Cmd+R.

이 패치는 **검증된 기존 코드와 다르면 수정하지 않고 중단**하며, 중복 적용할 수 있도록 만들었습니다. 적용 전 커밋/백업을 권장합니다. CI는 업로드 후 반드시 확인하세요.

추천 커밋명: `feat: 챕터별 탈출 준비 조건 강화 및 엔딩 테스트 갱신`
